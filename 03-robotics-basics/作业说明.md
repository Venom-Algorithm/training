## 基础作业：坐标换轴与角度计算

完成下面两个函数，对应讲义第 5、6 节。输入和输出都按 `(x,y,z)` 排列。

| 函数 | 输入 | 返回值 |
| --- | --- | --- |
| `optical_to_link(point_optical)` | 光学坐标：X 右、Y 下、Z 前。 | 同一个目标的相机机体式坐标：X 前、Y 左、Z 上。 |
| `aim_angles(point_reference)` | 云台零位参考系中的目标坐标：X 前、Y 左、Z 上，原点在两根转轴交点。 | `(yaw,elevation)`，分别向左、向上为正，单位 rad。 |

第一个函数根据两套轴向交换分量并处理正负号。第二个函数先用 `math.hypot(x,y)` 求水平距离，再用 `math.atan2` 求水平角和仰角。输入中出现 NaN、正负无穷，或水平距离小于等于 `1e-12 m` 时，抛出 `ValueError`。

删除对应函数中的 `raise NotImplementedError(...)`，填入实现。可以在 `code` 目录运行下面的调用，观察自己的返回值：

```bash
python3 - <<'PYCODE'
import math
from exercise import optical_to_link, aim_angles

print(optical_to_link((1, 2, 3)))
yaw, elevation = aim_angles((0, 1, 1))
print(math.degrees(yaw), math.degrees(elevation))
PYCODE
```

第一行应得到 `(3,-1,-2)`，第二行应约为 `90.0 45.0`。评价自己的实现时，结合方向看结果：光学坐标的右方对应机体式坐标的负 Y，下方对应负 Z；左侧目标的 yaw 为正，上方目标的仰角为正。再把角度输入改为 `(0,-1,-1)`，输出应约为 `-90.0 -45.0`。

对于正上方目标 `(0,0,1)`，以及包含 `math.nan` 或 `math.inf` 的输入，可以直接调用函数，观察是否按约定抛出 `ValueError`。显示数值时保留六位小数，便于和例子核对。

## 进阶作业：大小 yaw 的连续变换

先读[讲义](https://github.com/Venom-Algorithm/training/blob/main/03-robotics-basics/%E5%9F%B9%E8%AE%AD%E8%AE%B2%E4%B9%89.md)第 9.2 节，运行 `python3 big_small_yaw_demo.py`。示例采用“大 yaw 平台承载一侧小 yaw”的模型，两根转轴都竖直。目标位置由传感器给出，已经按小 yaw 的 X 前、Y 左、Z 上表达；两轴间的安装尺寸为练习参数。

完成 `small_yaw_to_base(point_small, big_yaw, small_yaw, small_offset, big_offset)`，返回目标在底盘中的三维坐标。参数约定如下：

| 参数 | 含义 |
| --- | --- |
| `point_small` | 目标在小 yaw 坐标系 S 中的 `(x,y,z)`，单位 m。 |
| `big_yaw` | 大 yaw 平台 L 相对底盘 B 的角度，单位 rad。 |
| `small_yaw` | 小 yaw 相对大 yaw 平台的角度，单位 rad。 |
| `small_offset` | 小 yaw 原点在 L 中的位置，用 L 的轴表达，单位 m。 |
| `big_offset` | 大 yaw 原点在 B 中的位置，用 B 的轴表达，单位 m。 |

两段角度都向左为正。先按小 yaw 角旋转目标，再加 `small_offset`，得到大 yaw 平台中的点；再按大 yaw 角旋转这个结果，加上 `big_offset`，得到底盘坐标。起始文件已导入 `rotate2d(x,y,yaw)`，可以调用两次完成水平旋转。Z 分量在每一段中加上对应偏移的 Z 分量。

例如输入点为 `(2,0,0.5)`，大 yaw 为 `π/2`，小 yaw 为 `-π/2`，两段偏移为 `(0.3,0.2,0)`、`(0,0,0.2)` 时，示例输出的大 yaw 平台坐标为 `(0.3,-1.8,0.5)`，底盘坐标为 `(1.8,0.3,0.7)`。用程序检查中间结果和最终返回值。

实现后，可以在 `code` 目录调用自己的函数：

```bash
python3 - <<'PYCODE'
import math
from exercise import small_yaw_to_base

point_base = small_yaw_to_base(
    (2, 0, 0.5), math.pi / 2, -math.pi / 2,
    (0.3, 0.2, 0), (0, 0, 0.2)
)
print(tuple(round(value, 6) for value in point_base))
PYCODE
```

将输出与上面的 `(1.8,0.3,0.7)` 核对。还可以用程序调整参数评价自己的实现：两段角度和偏移都设为零时，返回值应与输入相同；偏移为零、大 yaw 为 90°、小 yaw 为 0°时，输入 `(2,0,0)` 应得到 `(0,2,0)`；保留安装偏移时，可以在代码中打印大 yaw 平台坐标，与示例的中间结果逐项核对。
